# Veda AI Companion App

A telecom AI roaming companion POC with a FastAPI backend and React Native mobile frontend.

## Prerequisites 1

- **Python 3.9+** (for backend)
- **Node.js 18+** (for mobile app)
- **npm** or **yarn** (for package management)

## Project Structure

```
Veda_app/
├── backend/          # FastAPI application
│   ├── app/
│   ├── requirements.txt
│   └── tests/
└── mobile/           # Expo/React Native app
    ├── src/
    ├── package.json
    └── .env.example
```

## Backend Setup

### 1. Install Dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 2. Configure Environment

Create a `.env` file in the `backend/` directory with the necessary environment variables. Reference your existing configuration or ask your team lead for the required keys.

**Key variables:**
- `ANTHROPIC_API_KEY` — Your Anthropic API key
- `ANTHROPIC_MODEL` — Claude model to use:
  - `claude-haiku-4-5-20251001` (default, fastest & cheapest)
  - `claude-sonnet-5` (higher quality, slower & more expensive)

### 3. Run the Server

```bash
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

The backend will be available at `http://localhost:8000`

**Health check:** Visit `http://localhost:8000/health` to verify the server is running.

## Mobile App Setup

### 1. Install Dependencies

```bash
cd mobile
npm install
```

### 2. Environment Configuration

This project supports **two environments**: local development and Railway production.

**Environment files:**
- `.env.local` — Local backend (`http://localhost:8000`)
- `.env.dev` — Railway backend (`https://vedaapp-production.up.railway.app`)

**For local development** (backend running on your machine):
```bash
npm run start:local
```

**For Railway production** (using deployed backend):
```bash
npm run start:dev
```

The `.env` file is auto-generated by these scripts—do not edit it manually.

For detailed environment setup, see [ENVIRONMENTS.md](mobile/ENVIRONMENTS.md).

### 3. Run the App

**Local backend:**
```bash
npm run start:local
```

**Railway backend:**
```bash
npm run start:dev
```

Then choose your platform:

- **iOS Simulator:** Press `i`
- **Android Emulator:** Press `a`
- **Web:** Press `w`
- **Physical Device:** Scan the QR code with the Expo Go app

**Platform-specific scripts with environment control:**
```bash
npm run ios:local      # iOS + local backend
npm run android:dev    # Android + Railway backend
npm run web:local      # Web + local backend
```

See [ENVIRONMENTS.md](mobile/ENVIRONMENTS.md) for all available scripts.

## Signing In (POC Dev Login)

This is a POC, so real Supabase phone/OTP verification is stubbed out. The sign-in screen calls a
`dev-login` endpoint that skips OTP entirely.

1. On the sign-in screen, enter any phone number (e.g. `+15550001111`, matching the field's
   placeholder).
2. Tap **Sign in** — no OTP code is required.
3. The backend looks up a customer with that phone number and, if none exists yet, auto-creates
   one on the fly with placeholder details (`full_name: "New Customer"`, `telecom_plan: "Standard
   Mobile"`). Use the same number again later to sign back into that same dummy customer.

Notes:

- This only works because the backend's dev-login route (`POST /auth/dev-login`) is disabled
  whenever `ENVIRONMENT=production` — it's a dev/POC-only shortcut, not a real auth bypass.
- Any phone number works; there's no single fixed "seed" user, each unique number gets its own
  auto-created customer record.

## Deployment

### Railway (Backend)

The backend is deployed on [Railway](https://railway.app):

**Live URL:** `https://vedaapp-production.up.railway.app`

**Health check:** `https://vedaapp-production.up.railway.app/health`

**To deploy:**
1. Push to your GitHub repository
2. Railway automatically builds and deploys on every push
3. Check deployment status in Railway dashboard

**Environment variables on Railway:**
- `ANTHROPIC_API_KEY` — Your Anthropic API key
- `ANTHROPIC_MODEL` — Claude model (`claude-haiku-4-5-20251001` or `claude-sonnet-5`)
- `SUPABASE_URL`
- `SUPABASE_KEY`
- `SUPABASE_JWT_SECRET`

**To change the model in Railway:** Edit the `ANTHROPIC_MODEL` variable in the Railway dashboard. Changes deploy automatically on the next push.

## Quick Troubleshooting

| Issue | Solution |
|-------|----------|
| Backend won't start | Check Python version is 3.9+, verify all dependencies installed with `pip install -r requirements.txt` |
| Port 8000 already in use | Kill the process or specify a different port: `uvicorn app.main:app --port 8001` |
| Mobile app can't connect to backend | Use `npm run start:local` for localhost or `npm run start:dev` for Railway. Check `.env` file content. |
| Wrong API URL in mobile app | The `.env` file is auto-generated. Use `npm run start:local` or `npm run start:dev` (don't edit `.env` manually) |
| Dependencies not installing | Try deleting `node_modules` and `package-lock.json`, then run `npm install` again |
| Expo app not connecting | For local: make sure backend and mobile are on same network. For Railway: check internet connection and `https://vedaapp-production.up.railway.app/health` |
| Environment not switching | Run `npm run start:local` or `npm run start:dev` before starting the app (not just `npm start`) |
