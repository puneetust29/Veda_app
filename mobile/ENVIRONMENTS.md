# Environment Configuration Guide

This project supports multiple environments for connecting to different backends.

## Environment Files

- **`.env.local`** - Local development (connects to `http://localhost:8000`)
- **`.env.dev`** - Production/Railway (connects to `https://vedaapp-production.up.railway.app`)
- **`.env`** - Auto-generated by npm scripts (do not edit manually)

## NPM Scripts

### Local Development (Backend on Localhost)

```bash
npm run start:local      # Start Expo dev server
npm run android:local    # Start Android emulator
npm run ios:local        # Start iOS simulator
npm run web:local        # Start web version
```

Use these when your FastAPI backend is running locally:
```bash
cd backend
uvicorn app.main:app --reload
```

### Production/Railway Development

```bash
npm run start:dev        # Start Expo dev server
npm run android:dev      # Start Android emulator
npm run ios:dev          # Start iOS simulator
npm run web:dev          # Start web version
```

Use these when connecting to the Railway deployment.

## How It Works

When you run any of the environment-specific scripts (e.g., `npm run start:local`), it will:

1. Copy the appropriate environment file (`.env.local` or `.env.dev`) to `.env`
2. Start the Expo development server with that configuration
3. Your app will automatically use the correct API base URL

## Quick Start

**For local testing:**
```bash
npm run start:local
```

**For testing against Railway:**
```bash
npm run start:dev
```

Then press:
- `i` for iOS Simulator
- `a` for Android Emulator
- `w` for Web
- Scan QR code for physical device with Expo Go

## Environment Variables

### Local (`EXPO_PUBLIC_API_BASE_URL`)
```
http://localhost:8000
```

### Dev/Railway (`EXPO_PUBLIC_API_BASE_URL`)
```
https://vedaapp-production.up.railway.app
```

## Troubleshooting

If the app still connects to the wrong URL:
1. Check which environment file is active in `.env`
2. Clear Expo cache: `npm start -- --clear`
3. Restart your simulator/emulator
